
# NAVALHA

Projeto final da disciplina de Front-End — Desenvolvimento de um site para uma barbearia.

## Sobre o projeto

O NAVALHA é um site desenvolvido com o objetivo de apresentar os serviços de uma barbearia e facilitar o acesso dos clientes às suas principais informações.

## Funcionalidades

- Página inicial;
- Apresentação dos serviços e preços;
- Formulário de agendamento;
- Apresentação dos profissionais;
- Galeria de cortes e estilos;
- Informações de contato;
- Navegação entre as páginas.

## Tecnologias utilizadas

- HTML5
- CSS3
- JavaScript

## Estrutura do projeto

- `html/` — páginas do site;
- `css/` — arquivos de estilo;
- `js/` — funções JavaScript;
- `imagens/` — imagens utilizadas na galeria.

## Como executar

1. Baixe ou clone o repositório.
2. Abra a pasta do projeto no Visual Studio Code.
3. Abra o arquivo `html/index.html` no navegador ou utilize a extensão Live Server.

## Disciplina

Projeto desenvolvido para a disciplina de Front-End.
